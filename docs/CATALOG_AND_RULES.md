# مكتبة المنتجات وقواعد الربط

الملف: `level7mtm/resources/catalogs/level7_catalog_v1.json`. يُحرَّر من شاشة **محرر القواعد ← قواعد الربط**، ويُحفظ كل تعديل كإصدار جديد.

## البنية

```
المصانع
تعريفات القياسات   (مستقلة عن قيم العميل)
المنتجات
 └ ثوب سعودي  (ERP item 91001 / Saudi Thobe_TableMeasurement)
    └ الستايلات
       └ الشياكة 2027
          ├ البترون الأساسي: model_id + version + القطعة الأساسية 002
          ├ جدول القياسات: FL, SH, SLS, CH ...
          ├ مجموعات خيارات التصميم
          ├ القطع الأساسية (front, back)
          ├ قطع الإنتاج: النسخ، المعكوسة، المادة، التدوير، السماح بالعكس، معاينة، إنتاج
          ├ قواعد الربط
          └ قواعد خيارات التصميم: القطع، المتغيرات، الخصائص
```

## تعريف القياس (مستقل عن قيم العميل)

لكل قياس الحقول التالية:

| الحقل | المعنى |
|---|---|
| `code` | الرمز |
| `name` | الاسم بالعربية والإنجليزية |
| `unit` | الوحدة الداخلية (mm) |
| `kind` | النوع: طول، محيط، نصف محيط، عرض مسطح… |
| `method` | طريقة القياس |
| `order` | ترتيب الظهور |
| `visible` / `editable` | إعدادات الظهور والتعديل |
| `range_mm` | النطاق المقبول |
| `status` | حالة التأكيد |

ربط حقول ERP بهذه التعريفات يتم في ملف ربط ERP (`mappings/…`)، وفيه رمز ERP ووحدته في المصدر.

- **ارتفاع الرقبة `NH`** قياس عادي كبقية القياسات، ويتحكم في متغير X بقاعدة ربط. لا يوجد له محرك منفصل.
- لم تُضف له قاعدة ربط بعد، لأن متغير X المقابل له في ملف الـMDL غير معروف.

## قاعدة الربط (المحرر الموحد)

| الحقل | مثال | ملاحظة |
|---|---|---|
| المصدر | قياس `FL` أو خيار `collar=square` | |
| القطعة | `002` | |
| الإنشاء | `Basic-Construction 0` | |
| المتغير | `X1` | متغيرات القطعة الأساسية تُستخدم بأسمائها (`X1`)، ومتغيرات القطع الأخرى تُكتب `P005.X1` |
| القيمة أو المعادلة | `{M}` | `{M}` هو القياس المصدر بالملليمتر. `{CH}` قياس آخر من الطلب. يمكن استخدام متغيرات حُسبت بقواعد سابقة بأسمائها |
| الترتيب | 10 | ترتيب التنفيذ |
| المصانع / المقاسات | `*` أو قائمة | نطاق المصنع والمقاسات عند الحاجة |
| مفعّلة / الحالة | `confirmed` أو `proposed` | |

- **أكثر من قاعدة لنفس القياس مسموح.** مثال: FL يكتب `X1` في القطعة 002، ويكتب أيضًا متغيرًا في قطعة أخرى بمعادلة مختلفة.
- **قاعدتان تكتبان نفس المتغير:** القاعدة الأعلى ترتيبًا تفوز، ويُسجَّل ذلك كملاحظة «يحتاج مراجعة».
- **القياس المفقود لا يتحول إلى صفر:** تُتخطى القاعدة، فيبقى المتغير غير معرّف، ويوقف البترون الحساب برسالة واضحة.
- **القاعدة غير المؤكدة** (`proposed`) تمنع الاعتماد.

**مثال صاحب المشروع:** `FL → 002 → Basic-Construction 0 → X1` بالقيمة `{M}`. هذا إعداد قابل للتغيير لكل بترون، وليس ربطًا ثابتًا في الكود.

## خيارات التصميم وقائمة القطع

- **قاعدة الخيار:** تحدد القطع المطلوبة، والمتغيرات التي يضبطها الخيار (بالشكل نفسه: target و value و order)، وتعديلات خصائص القطع.
- **إعادة بناء القائمة:** تُبنى قائمة القطع من جديد في كل حساب، من القطع الأساسية مع قطع الخيارات المختارة. لذلك لا تتراكم قطع الخيارات السابقة عند تغيير خيار.
- **الظهور منفصل عن الإنتاج:** «في المعاينة» و«للإنتاج» إعدادان مستقلان. النستينج وملف DXF يأخذان قطع الإنتاج فقط، والمعاينة وملف PDF يأخذان قطع المعاينة.
- **قطعة غير موجودة في البترون:** إذا طلب الخيار قطعة لا يرسمها البترون الأساسي، يُسجَّل مانع للاعتماد `plan.piece_missing`، ولا تُخترع القطعة.

## الفصل بين الطبقتين

1. **الربط** (هذا الملف): قياسات وخيارات ← متغيرات البترون.
2. **الهندسة** (ملف البترون الأساسي `models/…`): متغيرات ← نقاط وخطوط ومنحنيات وقطع.

الحصول على قيمة X صحيحة لا يعني أن البترون صحيح. صحة البترون تُقاس بالتحقق الهندسي، ثم بالمقارنة مع المرجع، ثم بالتجربة الورقية وعينة الخياطة.
