# LEVEL7 MTM — دليل التثبيت والتشغيل

## التثبيت
1. شغّل `LEVEL7MTM-<الإصدار>-Setup.exe` على Windows 10/11 بنواة 64-bit. لا يلزم تثبيت Python.
2. اترك خيار «إنشاء أيقونة على سطح المكتب» مفعّلًا.
3. البيانات تُحفظ محليًا في `%LOCALAPPDATA%\LEVEL7 MTM`، وفيه قاعدة البيانات `level7mtm.db`
   والمجلدات `exports` (ملفات DXF وPDF) و`nesting` (ملفات النستينج) و`backups` (النسخ الاحتياطية).
   يمكن تغيير مكان البيانات بمتغير البيئة `LEVEL7MTM_DATA`.

المثبت غير موقّع رقميًا، لذلك قد يظهر تحذير SmartScreen عند تشغيله.

## التحديث أونلاين (بدون GitHub)

**التثبيت من GitHub مرة واحدة فقط.** بعدها:
- **البحث:** يبحث البرنامج عن إصدار جديد بعد التشغيل بثوانٍ، ثم كل 6 ساعات.
- **التثبيت:** عند وجود إصدار جديد تظهر رسالة فيها «تثبيت الآن» أو «لاحقًا» أو «تخطي هذا الإصدار». عند اختيار «تثبيت الآن»:
  1. يُحمَّل ملف التثبيت من صفحة إصدارات المشروع على github.com فقط.
  2. تُطابَق بصمته SHA-256 مع الملف المنشور، فإن اختلفت يُرفض.
  3. يُثبَّت بصمت، ثم يعمل البرنامج من جديد.
- **البيانات:** الطلبات والإعدادات والقواعد في مجلد البيانات، ولا يلمسها التحديث.
- **يدويًا:** قائمة مساعدة ← «البحث عن تحديثات…». ويمكن إيقاف البحث التلقائي من القائمة نفسها.
- **الإصدار المثبت:** يظهر في مساعدة ← حول البرنامج، مثل 0.1.13.
- **قد يسأل ويندوز للتأكيد** (SmartScreen / UAC)، لأن ملف التثبيت غير موقّع رقميًا.

## اللغة والدور
- من قائمة **عرض** اختر العربية أو English. الواجهة العربية تعمل من اليمين إلى اليسار.
- **المشغل** يرى شاشات العمل اليومية.
- **مطور البترون** يرى أيضًا «مكتبة الموديلات» و«محرر القواعد»، ويستطيع حفظ إصدارات جديدة من القواعد والإعدادات.

## سير العمل
1. **لوحة الطلبات**: استورد ملفات XML بإحدى الطرق التالية:
   - زر «استيراد ملفات XML».
   - سحب الملفات وإفلاتها على النافذة.
   - «مراقبة مجلد»: يُقرأ الملف بعد ثبات حجمه 3 ثوانٍ، ولا يُحذف الملف الأصلي. تُسجَّل الملفات الفاشلة، ويعيد زر «إعادة محاولة الفاشل» معالجتها.

   الملف المستورد سابقًا لا ينشئ طلبًا جديدًا. وصول رقم مراجعة أعلى (مثل `_3` بعد `_2`) ينشئ مراجعة جديدة، وتصبح المراجعة السابقة «مراجعة قديمة».
2. **تفاصيل الطلب**: يعرض كل قياس بمعناه ووحدته: قيمة المصدر بالسنتيمتر وقيمتها بالمليمتر. أي تعديل يدوي يحتاج سببًا ويُسجَّل، ويُبطل أي حساب سابق.
3. **اختيار الموديل والتصميم**: يعرض الموديل والخيارات وقيم X المحسوبة. اضغط «حساب البترون»؛ الحساب يعمل في الخلفية دون تجميد الواجهة.
4. **معاينة البترون**:
   - التكبير والتصغير بعجلة الفأرة، والتحريك بالسحب.
   - إظهار أو إخفاء خط القص وخط الخياطة والنوتشات واتجاه النسيج والنصوص.
   - المقارنة مع البترون قبل الانكماش، أو مع حساب سابق، أو مع مراجعة أخرى للطلب.
   - مواضع الأخطاء محاطة بدائرة حمراء.
   - المقياس الحقيقي لا يتغير بالتكبير، والخط المعلّم «100 mm» يوضح ذلك.
5. **نتائج التحقق**: تُعرض الملاحظات بثلاث درجات: مانع للاعتماد، يحتاج مراجعة، معلومة. زر «اعتماد» لا يعمل ما دام هناك أي مانع، ولا يوجد زر لتجاوز الموانع.
6. **اعتماد وإرسال للنستينج**:
   - يُنشأ ملف `.l7n` يُفتح مباشرة في LEVEL7 Nesting.
   - إعادة إرسال الطلبات نفسها لا تنشئ مهمة مكررة.
   - «تصدير تجريبي» ينشئ ملفًا اسمه يبدأ بـ `TEST-NOT-FOR-PRODUCTION` ولا يغيّر حالة الطلب.
7. **إعدادات المواد والتصدير**: نسب انكماش الطول والعرض لكل خامة. لا يمكن اعتماد أي طلب قبل تأكيد هذه القيم.
8. **سجل العمليات والنسخ الاحتياطية**:
   - «نسخة احتياطية الآن» تحفظ نسخة في مجلد `backups` بعد فحص سلامتها.
   - «استعادة نسخة» تحفظ قاعدة البيانات الحالية جانبًا، ثم تتطلب إعادة تشغيل البرنامج.

## الحالة الحالية (مهم)
الموديل المرفق `thobe-engine-test` **نموذج لاختبار المحرك فقط، وليس بترون الشياكة**. البرنامج يمنع اعتماده للإنتاج.
بترون الثوب الحقيقي يُضاف بعد استلام القواعد المطلوبة في `docs/OWNER_RULES_REQUEST.md`.

## سطر الأوامر
```
level7mtm-cli import Order-9-53-1_2.xml
level7mtm-cli list
level7mtm-cli calc 9-53-1_2
level7mtm-cli export 9-53-1_2 dxf -o out.dxf
level7mtm-cli nest 9-53-1_2 9-52-1_0 -o marker.l7n          (للطلبات المعتمدة فقط)
level7mtm-cli mdl-report "1-S- alshiaka-2027.mdl" -o reports
```
