# دليل إضافة موديل وتعديل القواعد

## المبادئ
- لكل نوع من المستندات التالية **إصدارات ثابتة**: الموديل، وملف ربط ERP، وجدول متغيرات X، وإعدادات المواد.
- أي تعديل يُحفظ كإصدار جديد، ولا يمكن تغيير إصدار محفوظ.
- الطلبات المحسوبة سابقًا تبقى مرتبطة بالإصدار الذي حُسبت به، ويمكن إعادة توليدها منه بالنتيجة نفسها.
- لا يُعتمد للإنتاج إلا موديل حالته `approved`. الحالات الممكنة:
  `engine_test` ← `draft` ← `in_review` ← `approved` ← `retired`.

## متغيرات X (طلب صاحب المشروع)
**محرر القواعد ← متغيرات X**. لكل صف:

| العمود | المحتوى |
|---|---|
| X | رقم المتغير كما في GRAFIS، مثل `X7` |
| قياسات المصدر | رمز أو أكثر من XML، مفصولة بفاصلة. يُستخدم أول رمز موجود في الطلب (مثل `COS, COG`) |
| المعادلة | اختيارية، وتُكتب بقياسات المصدر بالمليمتر، مثل `CH*2` |
| الحالة | `proposed` أو `confirmed`. الطلب لا يُعتمد ما دام يستخدم متغيرًا غير مؤكد |
| الدليل | من أين جاء الربط، مثل وصف معادلة Z |

ثم اضغط «حفظ كإصدار جديد».

## معادلات GRAFIS
1. **محرر القواعد ← معادلات GRAFIS ← فتح ملف MDL**: يعرض كل معادلات Z لكل جزء، مع الوصف العربي وسجل التعديلات.
2. «تجربة على طلب» تحسب قيم Z من قيم X للطلب المختار.
3. القيم من نوع AB وGL تظهر «تقاس في الإنشاء»، لأنها لا تُحسب من المعادلات وحدها.
4. التقرير الكامل يُنشأ بالأمر: `level7mtm-cli mdl-report ملف.mdl -o reports`

## ملف الموديل (JSON)
```json
{
  "format": "level7mtm-model", "format_version": 1,
  "model_id": "alshiaka-thobe", "version": "1.0.0", "status": "draft",
  "inputs":    [{"name": "X1", "label": {"ar": "الطول"}, "kind": "length", "range": [1000, 1800]}],
  "options":   {"collar": {"values": {"square": {}, "classic": {}}}},
  "constraints": [{"expr": "not (option.sleeve.kabak and option.jabzour.splender)", "message": "..."}],
  "variables": {"Z9": {"formula": "X3/2", "source": "grafis:part2:Z9"}},
  "points":    {"A": {"xy": ["0", "0"]}, "B": {"from": "A", "dx": "Z9", "dy": "-Z11"}},
  "paths":     {"shoulder": {"line": ["A", "B"]},
                "arm": {"curve": ["B", "C"], "start_angle": "-100", "end_angle": "0"}},
  "pieces":    [{"id": "front", "material": "O", "copies": {"normal": 1, "mirrored": 0},
                 "when": "option.collar.square",
                 "outline": [{"path": "shoulder", "edge": "shoulder", "allowance": "10"}],
                 "notches": [{"edge": "side", "dist": "len.side1"}], "grain": ["G1", "G2"]}],
  "seam_relations": [{"a": "front:side", "b": "back:side", "diff": "0", "tolerance": 1}],
  "checks": [{"id": "length", "measure": "-H.y", "target": "X1", "tolerance": 0.5}]
}
```

أنواع إنشاء النقاط:
- `xy` إحداثيات مباشرة.
- `from` + `dx`/`dy` إزاحة من نقطة.
- `polar` نقطة بزاوية ومسافة.
- `intersect` تقاطع خطين.
- `project` إسقاط نقطة على خط.
- `along` نقطة على خط حسب المسافة.
- `on_path` نقطة على مسار حسب المسافة.
- `mirror` انعكاس نقطة.
- `circle` تقاطع خط مع دائرة.

يجب أن يكون محيط كل قطعة (`outline`) مغلقًا وبعكس اتجاه عقارب الساعة. يمكن عكس اتجاه أي مسار بإضافة `-` قبل اسمه.

### خطوات التعديل
1. **محرر القواعد ← قواعد الموديل**: عدّل النص.
2. اضغط «تحقق»، فيُحسب الموديل على الطلب المختار وتظهر الأخطاء.
3. اضغط «حفظ كإصدار جديد» بعد رفع رقم `version`.

### خطوات الاعتماد
1. من **مكتبة الموديلات** احفظ نسخة حالتها `approved`.
2. يجب قبل ذلك اجتياز المقارنة مع مراجع GRAFIS، ثم التجربة الورقية، ثم عينة الخياطة.
